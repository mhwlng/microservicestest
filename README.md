
## java spring boot 4 microservice test

There are 4 services, each with their own docker container:

- api-gateway (4004)

  This is the standard spring boot microservice gateway and is the only part that is externally accessible.

  It is secured with a JWT token, generated by the auth-service.

- auth-service 

  Generates JWT tokens, only accessible inside docker, via auth-service:4005

  There is no functionality to add a new account.

  The auth-service automatically creates one record in the users table for testuser@test.com 

  There is one account stored in the postgres database: testuser@test.com password123

- task-service 

  Only accessible inside docker via task-service:4000

  Simulates a todo list, stored in the database with id, title, description, completed and created fields.
   
- micro-services-db 

  Postgres database, only accessible inside docker via micro-services-db:5432

There is also an end-to-end integration test project 

- integration-tests

  This is a standalone project, using rest-assured 5 and junit 6.
  Use 'test runner for java vscode extension' to run tests.

### Note that sensitive information like JWT secret, postgres user/password are only included for testing.

### Assuming, that the docker server runs on localhost:

## Get a JWT

http://localhost:4004/auth/login (POST)

IN:
{
    "email":"testuser@test.com",
    "password":"password123"
}

OUT:
{
    "token": "eyJhbGc............10Zy-E"
}

## validate JWT

http://localhost:4004/auth/validate (GET)

IN:
bearer token header

OUT:
200 ok


### For these endpoints, add Bearer Token header, requested previously

## Get all tasks

http://localhost:4004/api/tasks (GET)

Has request parameters: page, size, createdAt, sortDir

## Get task by id

http://localhost:4004/api/tasks/{id} (GET)

## Create a task

http://localhost:4004/api/tasks (POST)

IN:
{
    "title":"task 1",
    "description": "task a description",
    "completed":false
}

OUT:
{
    "id": 3,
    "title": "task 1",
    "description": "task a description",
    "completed": false,
    "createdAt": "2026-11-14T09:58:27.005775193"
}

## Update task

http://localhost:4004/api/tasks/{id} (PUT)

## Delete task

http://localhost:4004/api/tasks/{id} (DELETE)

## Get tasks by completion status

http://localhost:4004/api/tasks/completed/{status} (GET)

## Search tasks by title

http://localhost:4004/api/tasks/search-by-title (GET)

has request parameter: 'title'

## Search tasks

http://localhost:4004/api/tasks/search (GET)

Has request parameters: title, complete, page, size, createdAt, sortDir
